# v0.10.0 账号托管权限验收

日期：2026-10-27。Windows、Python 3.12、AstrBot 4.29.1；沿用 `.dev/astrbot-venv`。未修改原 info-agent 项目或真实运行配置。

## 交付行为

普通公开使用与账号托管分离。AstrBot 插件配置新增 `account_hosting_admin_only=true` 和完整身份例外名单 `account_hosting_users=[]`，仅宿主管理员配置可修改。私聊工具与个人来源页面不能提高托管权限。管理员身份按该用户会话的 admins_id 判断；名单按适配器、机器人实例、用户 ID 三项严格匹配。Dashboard 绑定使用被绑定档案的权限，不将 Dashboard 管理员权限转授给档案。

获准用户首次扫码前先提交指定说明，再请求二维码；记录说明版本，无需额外确认。说明提交异常不生成二维码，退出及重载不重复显示同版说明。官方适配器无送达回执，不能证明用户已阅读。登录入口、二维码轮询和落盘前、登录来源请求及后台健康检查均复核托管权限。撤销后清除当前凭据和待完成扫码并切回公开范围，历史数据不提升为公开范围。

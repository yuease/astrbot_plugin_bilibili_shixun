# v0.6.0：聊天设置与免登录临时搜索

本版完成聊天与页面的共享设置管理、匿名临时视频搜索和逐项查询诊断。保留现有登录、长期来源、采集历史及偏好数据，仍使用 runtime-direct-v1，不增加 RSSHub、独立服务或额外筛选模型。

## 可以这样使用

- “看看我长期订阅了哪些关键词、兴趣和来源，现在采集到哪一步。”
- “长期关键词加上天文，删掉旧词，其他订阅保持；开启关键词来源。”
- “兴趣改成偏重原理和观测方法，沿用之前学到的偏好。”
- “撤销刚才那次设置变更。”
- “临时去 B 站搜天文视频，不要加入订阅。”
- “设置保存好了，现在刷新来源，再看看已有结果。”

工具仅限当前配置的管理员私聊。模型先读取共享版本再修改；兴趣沿用学习目标。撤销必须给出变更编号及当前版本，只恢复目标字段，有同字段后续修改就拒绝覆盖。重复请求不会重复修改，其他订阅保留。

## 保存、采集与结果

设置回执明确返回 settings_saved、collection_started、needs_collection 和缓存转入数量。保存本身不会启动采集；刷新工具才联网读取已启用长期来源。仅关键词来源可匿名刷新，UP 和关注来源仍需扫码。

页面约四秒检查共享设置。未编辑的当前表单自动更新；有草稿时保留并提示重新载入，旧版本保存会被拒绝。Bot 修改长期兴趣默认延续既有学习；页面仍可显式选择新的学习目标。

## 临时搜索范围

新增 bilibili_search_videos_online：匿名搜索 B 站视频，按最新发布排序，一次读取一个远端页的 20 条候选，允许远端第 1–3 页。每条消息最多三次不同搜索，不要求先保存档案，也不写长期订阅或兴趣。命中是否与主题相关由聊天模型根据证据判断，不额外调用筛选模型。

默认最多等待十秒，可设 0–20 秒；超时不取消后台搜索。用 action=status 与 search_id 读取原任务，状态查询不联网。来源接口等待上限二十秒，失败与正常零匹配分开报告。

临时证据及任务结果保留 24 小时，每账号范围最多 200 条临时证据，账号切换后隔离。sources 中的 temporary_keyword 只读取已保留临时结果，不能替代联网工具。临时词只有在用户明确要求加入长期关键词后，才可能将未过期缓存转入长期来源；这也不代表再次联网。

## 查询诊断

每个请求的来源都会出现在 requested_sources 中，分别说明不存在、停用、未采集、失败、有旧内容、快照过早、采集成功为空或正常可查。混合查询只完成部分范围时明确返回 partial；部分来源不可用且零命中时是 partial_scope_no_match，不能概括成所有来源都没有更新。临时搜索失败也保留诊断。

本地 page、has_more、total_matches 与远端 remote_page、remote_has_more 分开。读完本地分页只代表当前保留匹配已展示完；远端覆盖继续看 coverage 与 scan，不把“未找到”解释成“没有发生”。

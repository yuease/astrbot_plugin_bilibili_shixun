## 测试中修正的问题

1. **送达状态过度承诺**：AstrBot官方event.send不返回送达回执，其内部也可能记录失败后无异常返回。官方图片现在返回status=submitted、delivery_confirmation=unavailable；sent计数保留兼容，含义为本次提交条数，不能解释为手机QQ已收到。工具指导明确不自动重发。二维码首次与复用回复也改用“提交”口径。
2. **页面说明不准确**：移除“必须管理员私聊”的旧说明，未绑定账号不显示自动通知承诺，官方模式明确在下一次使用插件时提醒。

最初浏览器用例把成功Toast误当成表单状态文字，已修正断言，并以真实保存的数据及后续完整流程核验。Playwright内置浏览器下载遇到连接中断，最终使用已安装Edge完成浏览器验收；不是跳过浏览器检查。

## 复现

使用Python 3.12，在仓库目录安装requirements-dev.txt；Node用于页面逻辑检查。Playwright浏览器可单独安装Chromium，Windows也可使用已安装Edge，或通过SHIXUN_BROWSER_CHANNEL明确选择浏览器通道。生产安装不需要开发依赖。

```text
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python -m pytest -q -p no:cacheprovider --tb=short tests
node --test tests/test_gui_sync.cjs
python -m ruff check .
python -m ruff format --check .
```

没有可用浏览器时浏览器测试会明确失败；Playwright库未安装时会显式跳过并反映在结果中，不能把这种运行称为完整通过。本次为0跳过。

# v0.11.0 管理员页面与订阅启停验收

2026-10-28。沿用 Windows / Python 3.12 / AstrBot 4.29.1 开发环境，未修改原 info-agent、真实凭据或部署配置。

## 行为

- `dashboard_bindings` 是一个字符串，只填管理员 QQ号或私聊 SID。官方机器人可从 `/B站状态` 或设置工具 `user_identity.sid` 获取 SID。用户须已是 AstrBot 管理员并有插件私聊档案；可先发送 `/B站状态` 建档，不要求扫码。
- 所有获准 Dashboard 登录账号都进入固定绑定的管理员档案，不再按 Dashboard 用户名分档。未填、无匹配、非管理员和多实例歧义均明确报错，不自动创建空档案。号码歧义时填写完整 SID。普通私聊用户仍互相隔离，页面绑定不提升非管理员权限。
- 不支持旧的多段绑定格式，不做迁移。
- 新增 `bilibili_set_subscription_enabled`，source=keyword_search/up/following。UP 必须已配置，保留其投稿/动态范围；关注 UID 来自当前用户的登录账号，可切换 videos/dynamics。开启私有来源检查托管权限和登录，关闭不要求登录。变更使用持久幂等、版本检查及已有撤销机制，保存不自动采集，不改其他用户或删除历史。Bot 新增工具需在人格中启用。
- `/B站登陆` 是 `/B站登录` 的别名，页面没有扫码登录入口。
